# Grading System

This Python program asks for a subject name and marks, then gives a grade.

## How It Works

- Type the subject name.
- Type the marks for that subject.
- The program gives a grade based on the marks.
- Type `done` when you have finished entering subjects.
- The program then prints all subjects, marks, and grades entered.

## Grades

- `70 - 100`: A Excellent
- `60 - 69`: B Very Good
- `50 - 59`: C Good
- `40 - 49`: D Fair
- `0 - 39`: Fail

## Run The Program

```bash
python twentyfifth.py
```
